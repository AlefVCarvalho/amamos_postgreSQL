Como utilizar

  1. Cadastre questões objetivas ou subjetivas.
  2. Monte uma avaliação, atribua pontos e selecione os alunos.
  3. O aluno acessa a avaliação e envia suas respostas.
  4. As objetivas são corrigidas pelo banco; o professor corrige as subjetivas.
  5. Consulte os relatórios de desempenho.
